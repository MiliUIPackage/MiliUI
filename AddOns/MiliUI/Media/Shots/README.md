# 插件總覽的預覽圖

「米利UI設定 → 插件總覽」右側詳情面板的擷圖放這裡。

- 檔名：`<名冊 key>.png`，key 就是 `Options/Roster.lua` 那一筆的 `key`
  （通常等於主資料夾名，例如 `MiliUI_UnitFrames.png`、`Cell.png`）。
- 尺寸：**840×420（2:1）**，顯示區就是這個比例，其他比例會被拉伸。
- 格式：PNG（路徑寫死帶 `.png` 副檔名，別放 TGA）。
- 不用改任何程式：檔案放進來、重開遊戲（新增檔案要重啟才會進客戶端的檔案清單，
  /reload 不夠）就會自動蓋掉佔位圖；沒圖的插件會顯示圖示＋「尚未提供預覽圖」。
