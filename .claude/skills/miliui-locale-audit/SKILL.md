# 語系對齊檢查

```
python3 scripts/locale_audit.py [插件資料夾]
```

不給路徑就預設檢查 `AddOns/MiliUI_UnitFrames`。有問題時回非零離開碼，可以串在其他檢查後面。

## 這套語系架構的前提

`Locales/Locale.lua` 建一張帶 `__index` 的表，**查不到就回傳 key 本身**：

```lua
ns.L = setmetatable({}, { __index = function(_, k) return k end })
```

所以 **key 就是英文原文**。三個推論，檢查項目都是從這裡長出來的：

- `enUS` / `enGB` 不需要語系檔
- 沒翻到的語系會退成英文，不會空白也不會壞 → 空殼檔是合法狀態
- **改 key 的文字 = 改了程式與所有語系檔的對照**，漏改一邊就靜默退回英文

## 八個檢查項目

| 項目 | 為什麼會出事 |
|---|---|
| 覆蓋率 | 原始碼用了、語系檔沒有 → 那條退回英文 |
| 多餘 | 語系檔有、沒人用 → 通常是 key 改過但譯文沒跟著改 |
| 重複定義 | 同檔同 key 兩次，**後面的靜默蓋掉前面的**，肉眼很難發現 |
| 格式符 | `L["Text %d"]:format(i)` 譯文漏掉 `%d` → 執行期才炸 |
| 色碼 | `\|cff…` 沒有對應的 `\|r` → 後面整段文字被染色 |
| 漏翻 | 譯文跟 key 一模一樣（只是提示，英文本來就可能相同） |
| 檔案守衛 | `if GetLocale() ~= "deDE"` 的代碼跟檔名對不起來 → 永遠不生效或蓋到別人 |
| TOC | 沒列到就永遠不載入；`Locale.lua` 要排在其他語系檔之前（它建 `ns.L`），全部要排在 `Core\Init.lua` 之前（那個檔載入時就用 L） |

`esES.lua` 同時守 `esES` 與 `esMX`（文字幾乎一樣，共用一份），腳本認得這種一檔多代碼的寫法。

## 常見修法

**「多餘」通常不是真的多餘**——是 key 改過、譯文留在舊 key 上。先比對「缺」與「多餘」兩張清單，多半一一對應。

**新增字串**：程式裡寫 `L["English text"]`，然後每個有翻譯的語系檔補一行。跑這個腳本確認沒漏。

**要刪 key**：程式與所有語系檔一起刪，跑腳本確認「多餘」是空的。

## 順帶一提

`luac -p` 只驗語法，抓不到「用了 L 但檔案沒宣告 `local L = ns.L`」——那是另一個坑，用 `luac -l` 掃 `_ENV` 讀取（見 memory 的 `wow-luac-global-scan`）。
