2026-11-04 NGA 玩家問「冷卻管理器自帶的施法條能不能彩虹色」，先做彩虹（靜態＋流動），使用者說效果很好，11-06 再加
宇宙星辰／閃電／熔岩（流火）／火焰（火舌）四款；11-10 使用者要「日式櫻花飄、帶台灣特色的」，看過草稿後七款全接
（櫻花、青海波、天燈、客家花布、老花磚、珍珠奶茶、極光）。貼圖全部腳本算的、不帶別人的檔（SharedMedia 那包 statusbar 貼圖沒授權檔，不拿來改）。

- **登記表** `Core/Media.lua` 的 `M.FX[token] = { tex, layers }`：`tex` 是靜態填充（也登記進 LSM），`layers` 由下往上，
  只有兩種層——`scroll`（REPEAT 平鋪＋`TextureCoord` 動畫橫向捲，可 `blend="ADD"`／`twinkle`；11-10 加 `vy`：同一輪裡直向捲整數個貼圖高，花瓣飄落／天燈上升）與 `flip`（FlipBook，可 `pause`／`overflow`）。
  加一款只動登記表與產圖腳本，引擎不用動；另外要進套組名冊（[[project-miliui-media-naming]]：中文顯示名「米利UI: 宇宙星辰／閃電／熔岩／火焰」）再跑 sync-widgets。
- **引擎** `Modules/Castbar.lua`「效果層」：裁切框錨在填充貼圖前緣（秘密模式照常、全程引擎跑），狀態色要露出時把層壓透明
  （不可打斷 → 裁切框、斷法就緒 → host，秘密布林餵 `SetAlphaFromBoolean`）。後來別的 session 把引擎改成收「宿主」的形式，
  專注目標施法條與設定頁的內嵌樣本都共用（以程式為準）。
- **設定**：`animate`／`animSpeed`（倍率），設定頁兩列與說明只在選到動畫材質時出現（使用者 11-06 同意：永遠灰著的列是雜訊）。
  DB v15 把只活兩天的 `rainbowFlow`／`rainbowFlowSpeed`（一輪幾秒）搬過來。
- **產圖**：彩虹 ＝ 技能 `miliui-cdm-rainbow-texture`；其餘 ＝ `miliui-cdm-castbar-fx`（`fx.py` 第一批十張、`fx_themes.py` 第二批二十張；閃電 import 天空騎術那支的折線演算法）。
  第二批全是捲動層、每款 50 KB 以下——**主題圖樣類的皮膚用捲動層就夠，別動用序列圖**。
- **流程上有效的做法**：先把候選貼圖照遊戲的合成規則畫成一頁即時預覽給使用者看，再決定接哪幾款（使用者看完說四款都接）。
  火焰這種靠參數的東西尤其要先看草稿。
- **實機狀態**：十九款全部實機正常（設定頁樣本／預覽，明文模式）——前十三款 2026-11-10、第三批六款（紅葉／螢火蟲／錦鯉水波／夜市霓虹／藍白拖／台灣藍鵲）與收條閃跳的修正 2026-11-11。含直向捲動方向（`SetOffset(dir, -vy)` 正＝往下飄）、直向 REPEAT 無接縫、帶 alpha 的貼圖沒有黑邊、`Pause` 之後 `Play` 會接著播。
  **還沒看過**：副本裡（秘密模式）的裁切與不可打斷讓位。踩過的坑：[[wow-createanimation-texturecoord-type-name]]。
- **收條前的過場不要 Stop 效果層**（11-10 使用者回報「唱完、中斷的瞬間圖案跳回第一格、有閃爍感」）：Stop 會把貼圖座標歸零再露出靜態填充。
  改成唱完邊淡出邊照播、被打斷／失敗 `Fx.Pause` 凍結＋`Fx.Tint` 染打斷色、真的收條才 Stop（玩家與專注目標兩條都是）。
- **使用者的口味**（11-10）：喜歡有文化主題的圖樣，主動點名日式與台灣特色；三輪草稿幾乎全收。**台灣藍鵲**第一版（兩排尾羽的特寫）被退：「先不用，或改一下讓他更有質感」；11-11 第二版改畫「一列藍鵲飛過山嵐」（鳥本身＋三層山的視差）就收了。
  **教訓：動物／植物主題畫「牠在場景裡」，不要畫身上紋理的特寫**；景深用幾層不同速度的捲動層就有。
  夜市霓虹的招牌字用思源黑體畫（字型在 `~/MiliUI-Fonts/字型母版/`，不在 repo）。

**How to apply:** 玩家再要新皮膚先看能不能用兩種層疊出來；回報「動畫沒動／錯位」先問是不是秘密模式（副本內）才壞。
