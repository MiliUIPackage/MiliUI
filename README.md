# 米利UI套組 MiliUI Package

魔獸世界（正式服）的整合 UI 套組：11 支自製插件 ＋ 一批挑好、調好預設值的第三方插件，
解壓縮就能用。

**下載與討論：** [addons.miliui.com](https://addons.miliui.com)

---

## 安裝

這個 repo **就是一份 `Interface/` 資料夾**，不是「一個插件」。

1. 關掉遊戲。
2. 下載這個 repo（`Code → Download ZIP`，或 `git clone`）。
3. 把裡面的 `AddOns` 資料夾覆蓋到
   `World of Warcraft\_retail_\Interface\AddOns`。
4. 進遊戲，在角色選單的「插件」確認都有勾。

> **更新的時候一樣是覆蓋。** 舊版留下來、新版已經移除的插件資料夾不會自己消失
> —— 插件沒有權限刪硬碟上的東西。套組會偵測到那些殘留並自動停用它們，
> 也可以自己把資料夾刪掉。

設定都存在 `WTF\`，覆蓋 `AddOns\` 不會動到你的設定。

## 進遊戲之後

按 `Esc`，遊戲選單上會多一顆 **米利UI設定**；滑鼠移過去會展開套組裡每一支插件的入口。
小地圖旁邊的 MBB 按鈕也是同一張選單。

或者直接打指令：

| 指令 | 開什麼 |
|---|---|
| `/miliui`（或 `/mili`） | 套組本體：插件總覽、插件強化、效能監控、預設值匯入 |
| `/muf` | 米利的單位框架 |
| `/mtip` | 米利的滑鼠提示 |
| `/mdm` | 米利的傷害統計 |
| `/mfocus` | 米利的焦點助手 |
| `/mnote` | 米利的角色筆記 |
| `/maura` | 米利的光環美化 |
| `/mchatbar` | 米利的快捷聊天列 |
| `/mbh` | 米利的爆發藥水助手 |
| `/blm` | 米利的嗜血音樂 |
| `/agsc` | 冒險指南天賦比較 |
| `/rl` | 重載介面 |

**「插件總覽」那一頁可以直接開關套組裡的每一支插件**，不必去角色選單找。

## 套組自製的插件

| 插件 | 做什麼 |
|---|---|
| **米利的單位框架** | 取代暴雪的頭像框：玩家／目標／目標的目標／專注／專注的目標／寵物／首領，含施法條、光環過濾、職業資源條、3D 頭像、距離淡出。團隊框架交給 Cell。 |
| **米利的滑鼠提示** | 重寫的工具提示：陣營／職業配色、血條、目標行、3D 模型、物品與法術 ID。 |
| **米利的傷害統計** | 走暴雪 12.1 的 `C_DamageMeter`，完全不解析戰鬥記錄，成本只跟看得到幾列有關。 |
| **米利的焦點助手** | 焦點施法條、斷法巨集、標記列。 |
| **米利的角色筆記** | 副本／首領筆記，可以貼連結分享給隊友。 |
| **米利的光環美化** | 增益／減益圖示的外觀、倒數與層數字型。 |
| **米利的快捷聊天列** | 一排按鈕直接切頻道，可以磁吸在聊天視窗旁邊。 |
| **米利的爆發藥水助手** | 一鍵切換要用哪支爆發藥水，巨集不用改。 |
| **米利的嗜血音樂** | 嗜血／英勇時放自訂音樂，含倒數條。 |
| **冒險指南天賦比較** | 冒險指南裡比較同職業不同專精的掉落。 |

其餘資料夾是第三方插件，除了少數幾支帶有本地修改之外都是上游原樣。
各自的授權檔在各自的資料夾裡。

## 回報問題與翻譯

問題請到 [addons.miliui.com](https://addons.miliui.com) 的頁面下方留言，或在這裡開 issue。
回報時附上 `/miliui debug` 或該插件的 `debug` 指令輸出（例如 `/muf debug`）會快很多。

**翻譯**：自製插件的語系檔在各自的 `Locales/`。新的那幾支用「英文原句當 key」，
少一條就退回英文顯示、不會壞掉，所以只補你有把握的那幾句也沒問題。歡迎 PR。

## 開發

給要動這個 repo 的人：

```bash
bash .claude/scripts/check-all.sh    # 提交前跑一次（語法、TOC、語系）
```

慣例與各插件現況寫在 [CLAUDE.md](CLAUDE.md) 與 [.claude/notes/](.claude/notes/)。
這兩個位置與 `.github/` 都設了 `export-ignore`，不會進玩家的發佈包。
